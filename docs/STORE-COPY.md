# Store listing copy

Paste-ready. Changing any of this needs a listing submission (no new package,
but it does go through review).

Rules this copy follows, because the previous version broke all four:
1. **No dashes standing in for punctuation.** Em dashes in every other
   sentence are the clearest tell that a machine wrote the text.
2. **Concrete over abstract.** "Timed to the second" beats "powerful timing
   features".
3. **Short sentences.** The store truncates the description after roughly two
   lines in search results, so the first two lines carry the whole pitch.
4. **No claim the product cannot back up.**

## Description

```
Ask one question. Get five answers.

You already pay for more than one AI. But asking them the same thing means
typing it five times, in five tabs.

whileAI does that part for you. Type your prompt in ChatGPT, Claude,
Perplexity, Gemini or DeepSeek, and the same prompt appears in whichever of
the others you switched on. Your tabs, your accounts, your subscriptions. No
API keys, no sign-up, no middleman server.

It also times every answer, because waiting is the part nobody measures. The
dashboard shows which AI is slowest, how long you waited this week, and how
often you tabbed away mid-answer.

WHAT YOU GET
One prompt, up to five AIs, each in its own tab.
A queue, so a second prompt waits its turn instead of colliding.
A switch per AI, so only the ones you pick receive anything.
A timer on every answer, with a dashboard you can export.
A warning when an AI needs you: signed out, rate limited, or showing a check.

HOW IT BEHAVES
whileAI works inside sessions you signed into yourself. It types into the
message box and clicks send, one prompt at a time, at human pace. It does not
solve CAPTCHAs, work around usage limits, open hidden sessions, or pretend to
be a different browser. When a site puts up a check or says you have hit a
limit, whileAI stops and tells you.

PRIVACY
Your prompts and timings stay in your browser. No account, no analytics, no
telemetry. whileAI never reads what the AIs write back. It watches only
whether an answer is still arriving, so it can time it. You sign in yourself,
so it never sees a password.

PRICE
Free. Every feature, no limits, no trial.

Not affiliated with OpenAI, Anthropic, Perplexity, Google or DeepSeek.
```

## Why the "Site & privacy: <url>" line was removed

Chrome Web Store descriptions are **plain text**. A URL typed into the
description renders as characters, not as a link, which is why that line was
dead weight on the old listing: nobody can click it.

The links that ARE clickable come from dashboard fields, so fill those in
instead:

| Dashboard field | Value |
|---|---|
| Homepage / Website | `https://ahmetaytar.com/whileai` |
| Support URL | `https://ahmetaytar.com/whileai#help` |
| Privacy policy URL | `https://ahmetaytar.com/whileai/privacy` |

Keep all three. The privacy policy URL is required for any item that handles
user data, and "Support" is where a confused user goes before they leave a one
star review.
